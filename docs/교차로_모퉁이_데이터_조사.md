# 교차로 모퉁이 5m 데이터 조사 (2026-10-22)

도로교통법 제32조 2호는 "교차로의 가장자리나 도로의 모퉁이로부터 5m 이내"를 주정차 금지 구역으로 정해요. 주민신고 6대 구역 중 Statio에 아직 없는 유일한 구역(인도 제외)이라 데이터를 찾아봤어요. **2026-10-27에 신호 교차로를 1차 버전에 넣었어요.** 아래 '적용 결과'를 보세요.

## 결론
- **서울 신호 교차로는 바로 받을 수 있어요.** 서울시 교통안전시설물 '교차로'가 Open API(`trafficSafetyA008PInfo`)로 열려 있고, 좌표를 실제로 받아 검증했어요.
- **골목(신호 없는) 교차로는 공개 API가 없어요.** 도로명주소 실폭도로나 OpenStreetMap에서 계산해야 하고, 이용 조건부터 확인해야 해요.
- 2차 계획: 신호 교차로를 '교차로 모퉁이(추정)' 위험 지점으로 넣고, 골목 교차로는 이용 조건 확인 뒤 판단해요.

## 서울 교차로 API 검증 (2026-10-22)
- 8,638건을 모두 받았고, 535건은 좌표가 `null`이에요. 좌표계는 EPSG:5186이라 횡단보도와 같은 변환(`datapipe/build_risk_db.py`의 `tm5186_to_wgs84`)을 써요.
- 교차로 811곳(10곳마다 1곳)에서 가장 가까운 횡단보도까지 거리를 재 보니 **중앙값 8.5m, 96%가 30m 안**이었어요. 좌표 변환이 맞고, 점이 실제 교차로 자리에 찍혀 있어요.
- 이름에 "(연등)", "(경보)" 같은 신호 운영 표시가 붙어 있어 신호 교차로 대장으로 보여요. 유형 코드는 001 4,819 / 002 1,905 / 003 1,891 / 004 22 / 005 1건이에요(뜻은 정의서 PDF로 확인 필요).
- 위경도 범위에 서울 밖 값이 조금 섞여 있어(위도 37.20, 경도 127.53까지) 서울 범위로 걸러야 해요.
- 시연 위치와의 거리: 광화문 세종대로 32m("KT앞"), 용산 원효로 69m, 종묘 앞 105m. 모두 5m 기준 밖이라 지금 시연 결과는 바뀌지 않아요.

## 처음 세운 적용 계획 (10/22)
1. `datapipe/fetch_seoul_data.py`에 `trafficSafetyA008PInfo`를 더하고, 좌표 없는 행과 서울 밖 행을 걸러요.
2. 위험 종류 `intersection`(교차로 모퉁이, 추정)을 더해요. 점 데이터라 반경은 '교차로 반폭 + 5m'로 잡아요.
   - 반폭은 OA-23081로 같은 교차로의 횡단보도까지 거리를 재서 교차로마다 정해요. 못 구하면 기본 15m(반경 20m)로 둬요.
3. 화면에는 "교차로 모퉁이(추정)"로 보여 주고, 과태료는 다른 주민신고 구역과 같은 승용차 4만 원 추정으로 둬요(공식 금액 확인 필요).
4. `server/parking_core.py`, Kotlin `RiskKind`, 앱 내장 DB, 정답 사례(`GoldenCasesTest`)를 함께 갱신해요.
5. 골목 교차로는 실폭도로 이용 조건을 확인한 뒤 판단해요.

## 적용 결과 (2026-10-27, 1차)
계획과 다르게 정한 것만 적어요. 자세한 규칙은 `datapipe/README.md`의 '교차로 모퉁이'에 있어요.
- **반폭:** OA-23081(엑셀) 대신, 이미 받고 있는 횡단보도 API(OA-15554)에서 중심점 5m 밖의 가장 가까운 횡단보도까지 거리를 썼어요. 중심점 바로 위의 횡단보도는 가장자리를 알려 주지 않아서 빼요. 판단 반경은 10\~35m, 중앙값 15m예요.
- **길 중간 횡단보도 신호 빼기:** 신호 교차로 대장에는 길 중간 횡단보도 신호도 섞여 있어요(예: 광화문 'KT앞'). 중심점 5m 안에 횡단보도가 있고 주변 횡단보도가 모두 한 방향으로 늘어선 941곳은 모퉁이가 없다고 보고 뺐어요.
- **유형 코드:** 001\~004 모두 주변 횡단보도 수가 많아(중앙값 6\~20개) 실제 교차로로 보고 모두 넣었어요. 번호가 클수록 횡단보도가 많아 교차로 크기 구분으로 보여요.
- **결과:** 7,158곳. 앱 DB에 지점별 반경(`radius_m`)을 더했고, 파이썬 기준 구현·Kotlin·정답 사례(교차로 근처 10곳 포함)가 같은 답을 내요. 시연 위치 세 곳의 결과는 바뀌지 않았어요.
- **남은 것:** 골목 교차로(실폭도로 이용 조건 확인 뒤), 과태료 공식 금액 확인.
